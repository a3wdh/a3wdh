## Guess a Mother Name

This repository includes a small Python script to guess a likely mother's name from a given child's name. The guess is deterministic for a given input but entirely heuristic and not accurate.

Run the script with:

```bash
python guess_mother_name.py <child_name>
```

It prints the guessed mother name for the provided child name.
